# AF–02 inspection preview

The standalone preview is at `/inspection/` in the V2.1 build. Run `npm run build` and `npm run serve` from `web`, then open [the local preview](http://127.0.0.1:4173/inspection/). Open Airfoil editor goes to the existing isolated 2D section editor and its ONNX predictions.

In the first pass, inherited page styles narrowed the viewport and the perspective camera cut into the front wing. The second pass expanded the bay, fit the perspective camera to the car's full envelope, and reduced grid aliasing at shallow viewing angles. The front, side, and top lenses use orthographic projection. The default three-quarter view uses perspective.

## Model source and licensing

AF–02 is original AeroForge geometry generated by [generate-inspection-car.mjs](../../web/scripts/generate-inspection-car.mjs). The mesh uses interpolated rings, shaped wing blades, lathed slick tires, and separately named assemblies for suspension, wings, halo, sidepods and wheels. The front wing has its own named inspection anchor. The model has original colors and no team marks, external textures, or imported vehicle geometry. The [repository MIT license](../../LICENSE) covers the original generator, its emitted vehicle and the preview render.

Run `node scripts/generate-inspection-car.mjs` from `web` to regenerate the GLB with the pinned Three.js package. The binary uses glTF 2.0 with indexed positions and normals and one merged draw per assembly and material. The poster is a WebP capture of the rendered three-quarter view, with no additional art source. Serve the asset under a new versioned path whenever published bytes change. [Vehicle and poster](../../web/public/vehicle/af02-v1/)

The GLB is 828,248 bytes. Its SHA-256 is `98730eb9b526bb7b0be824c75ff9e5e76255d32da8e7ef73ab92e9150f2b8f7f`. The desktop render measured 35,606 triangles and 34 draw calls, including the floor. The five deferred graphics chunks total 1,008,716 decoded bytes and 269,832 gzip bytes. The prototype phone opt-in uses the same GLB. The smaller mobile asset and physical-device performance pass are scheduled for V2.5. The export includes the Three.js and React Three Fiber MIT notices. [Pinned Fiber license](https://raw.githubusercontent.com/pmndrs/react-three-fiber/v9.8.2/LICENSE)

## Browser behavior

Desktop loads the preview on demand after detecting WebGL2. Phones show the poster and expose an explicit 3D opt-in. Missing WebGL, a failed mesh request, and graphics context loss retain the static poster and the route to the airfoil editor. The scene uses demand rendering with no animation at rest. Scene teardown aborts in-flight downloads, removes controls and listeners, and disposes the renderer-owned and model-owned GPU resources.
